# React Basics

React helps you build interfaces from small, reusable components. Each component owns a focused piece of UI and can receive data through props.

## Components and props

A component is a function that returns UI. Props let a parent pass information into a child without tightly coupling the two pieces.

## Hooks

Hooks such as `useState` and `useEffect` let function components manage state and synchronize with external systems. Keep each effect focused so the data flow remains easy to understand.

## A useful habit

Start with the smallest component that expresses one idea, then compose it into a larger page. This keeps React code easier to test, reuse, and maintain.
